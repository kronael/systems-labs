# Two further design questions

Why a store's refusal to complete a unit of work is a different kind of
failure from a write it rejects as invalid, and what the application must own
for the first kind that it does not own for the second; and why a decision
that reads a set of records and writes into that same set can be refused even
when every individual write it made was legal on its own.
